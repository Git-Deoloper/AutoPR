# Project status

AutoPR hosts LocalClaw, an alpha Python CLI and JSON API for an Ollama-backed code assistant. Current functionality, setup instructions, and known limits are maintained in [README.md](README.md).

Implemented areas: code-file prompts, model management, workspace scanning, bounded source context, a local API, regression tests, and package build configuration.

Future ideas include a visual editor, explicit patch review, and pull-request integration. Those features are not implemented by the current release.
