# Getting started

Follow the [README](README.md#quick-start) for verified installation commands and configuration. The source package is named LocalClaw and is maintained in the AutoPR repository.

Useful next steps:

1. Run `localclaw --help` to inspect available commands.
2. Use `localclaw setup --list-models` to see installed model tags.
3. Analyze a small, non-sensitive file before querying a larger workspace.
4. Review generated suggestions and run your own tests before applying them.
5. Read [API.md](API.md) to use the JSON API.

No PyPI release, autonomous PR workflow, or visual code editor is promised by this version. Model inference is local only when `OLLAMA_BASE_URL` points to a local server.
